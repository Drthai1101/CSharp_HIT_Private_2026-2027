Họ và tên: Đặng Quang Thái

Mục tiêu học tập: Học C# và Unity để phát triển kỹ năng lập trình game, xây dựng nền tảng cho dự án cá nhân.

Công cụ sử dụng: Visual Studio, Unity, Git, GitHub.

Các khái niệm Git cơ bản: 
    + Clone: Tạo bản sao repository từ GitHub về máy tính để làm việc.
    + Commit: Lưu lại thay đổi trong lịch sử Git, kèm mô tả.
    + Push: Gửi các commit từ máy tính lên repository từ xa, chẳng hạn GitHub.
    + Pull: Lấy các thay đổi từ repository từ xa về và tích hợp vào nhánh hiện tại.
